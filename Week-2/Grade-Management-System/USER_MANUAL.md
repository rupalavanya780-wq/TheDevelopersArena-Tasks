# User Manual

When the program starts, a menu with seven options appears.

1. **Add student marks** — Enter a student's name and marks for Mathematics, Science, English, History, and Computer. Each mark must be from 0 to 100.
2. **View all students** — Displays every stored student, subject marks, and average.
3. **Calculate averages and grades** — Displays each student's average, highest mark, lowest mark, and grade.
4. **Find top performer** — Displays the student with the highest overall average.
5. **Search student** — Enter the student's full name. The search ignores uppercase/lowercase differences.
6. **Generate performance report** — Displays subject-wise averages, class average, grade distribution, and top performer.
7. **Exit** — Ends the program.

## Input rules

- Student names cannot be empty.
- Menu choices must be whole numbers from 1 to 7.
- Marks must be numeric values from 0 through 100, inclusive.
- If an invalid value is entered, the program displays an error and asks again.

## Storage

Student data is held in memory in arrays. Closing the application clears the records. Enter the records again when restarting the program.
