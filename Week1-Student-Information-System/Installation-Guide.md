# Installation Guide

## 1. Project Requirements

- Java Development Kit (JDK)
- A text editor or Java IDE, such as Visual Studio Code, IntelliJ IDEA, or Eclipse
- Command Prompt or terminal

## 2. Verify Java Installation

Open a terminal and run:


java -version
javac -version

Both commands should display the installed Java version.

## 3. Compile the Application

1. Open the project folder in your terminal.
2. Navigate to the 'src' directory.
3. Compile the source files:

javac Main.java Student.java StudentManager.java

## 4. Run the Application

After successful compilation, execute:

java Main

The Student Information System menu should appear in the terminal.

## 5. Troubleshooting

- If 'javac' is not recognized, verify that the JDK is installed and configured.
- If a file is not found, check that the terminal is in the correct directory.
- If compilation fails, review the error message and check the Java class and file names.
