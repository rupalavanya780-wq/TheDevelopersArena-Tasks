# Student Information System

## Project Overview

The Student Information System is a Core Java console-based application developed as part of the Week 1 Java Basics and Programming Fundamentals project.

It allows users to manage student records through a menu-driven interface.

## Features

- Add new student records
- View all students in a formatted table
- Search students by Student ID
- Update existing student details
- Delete student records
- Validate Student ID, name, age, grade, and contact information
- Prevent duplicate Student IDs
- Handle invalid inputs
- Store student records using ArrayList

## How to Run

1. Open a terminal in the project folder.

2. Navigate to the `src` directory.

3. Compile the Java files:

   `javac Main.java Student.java StudentManager.java`

4. Run the application:

   `java Main`
